# ex00 - ft_strcmp

## Subject  
> Reproduce the behavior of the function strncmp (man strncmp).

## Objective  
> Understand how string comparison works.

## Going further  
> In the return statement, why do we cast `s1[i]` and `s2[i]` to `unsigned char` before subtracting?  
> What could happen if we omit these casts, especially when dealing with characters outside the standard ASCII range (values above 127)?
