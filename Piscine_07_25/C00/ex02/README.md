# ex02 - ft_print_reverse_alphabet

## Subject  
> Create a function that displays the alphabet in lowercase, on a single line, in descending order, starting from the letter ’z’.

## Objective  
> Learn how to use `while` loops and character iteration in more depth.

## Going further   
> Why is it useful to store characters as int when manipulating them in loops?  
> How can using char instead of int affect arithmetic operations on characters?
