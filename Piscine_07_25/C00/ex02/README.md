# ex02 - ft_print_reverse_alphabet

## Subject  
> Create a function that displays the alphabet in lowercase, on a single line, in ascending order, starting from the letter `'a'`.

## Objective  
> Learn how to use `while` loops and character iteration.

## Going further  
> In the line `int alpha = 'a';`, why is the character `'a'` assigned to an `int` variable instead of a `char`?  
> What would change if we used `char` instead of `int`?
