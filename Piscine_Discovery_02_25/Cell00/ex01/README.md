# ex00 - Z

## Subject 
> Create a file called z that returns "Z", followed by a new line, whenever the cat
command is used on it. 

## Learning Objectives 
- Learn how to create a file using command line
- Practice basic file writing and redirection

## Solution

1. 
    `touch z` *use this command to create the file*
    *Then use your favorite text editor and add a Z in the file*

2.
    `echo Z > z` *this command writes the caracter Z into a file named z*
